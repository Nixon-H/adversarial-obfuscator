# Threat Model — shadow-compiler

Scope: the build-time obfuscation pipeline (`scripts/build.py`,
`obfuscator/`, `irgen/`, `native/`) and the loader gates it emits into
artifacts (anti-VM, trial/HWID, watermark, frozen-stdlib snapshot,
stdlib-audit, audit-hook plant detector, BYOVD driver gate, kill ladder).
Out of scope: research/experimental flags (FHE-VM, iO, ZK, GPU/TEE/SGX,
distributed execution) unless stated.

Every `Detection` cell was verified against this tree with `grep`.
`UNVERIFIED` means no in-tree evidence was found — treat the row as
residual risk, not as coverage.

| Threat | Attack surface | Detection (file:line) | Mitigation | Residual risk |
|---|---|---|---|---|
| Malicious local admin (root / Administrator) | Whole host: artifact memory, key material, state files | None — UNVERIFIED (no detector can run above its attacker) | None; admin reads `BLOB_KEY` from process memory regardless of wipe-on-kill | **HIGH**. Accepted: tool raises analyst cost, does not resist root. |
| Unprivileged attacker (same user / other local user) | Loader gates, trial state files, `build/` artifacts | Gates below (trial, watermark, snapshot, stdlib-audit) | Fail-closed kill ladder: wipe + `os._exit(137)` (`obfuscator/kill_ladder.py:44`, `obfuscator/kill_ladder.py:188`) | Medium: attacker can still copy artifacts offline and attack statically. |
| BYOVD attacker (vulnerable signed driver) | Kernel via known-vulnerable drivers (WinRing0, etc.) | `obfuscator/driver_blocklist.py:36` (blocklist), `obfuscator/driver_blocklist.py:246` (`is_armed`), native gate `native/stub_win.cpp:643`, `native/stub_win.cpp:681`, `native/stub_win.cpp:719` | Read-only enumeration + blocklist compare; when armed (`--driver-check` / `NIXON_DRIVER_CHECK=1`), `_nx_kill("driver-blocked")`. No loading, no IOCTLs (`obfuscator/driver_blocklist.py:1`, `native/stub_win.cpp:647`) | Medium: gate is opt-in (default disarmed); enumeration is point-in-time + 60 s re-check thread only. |

| Malicious config (poisoned `config/*.json`, build flags) | `config/default.json`, `config/relay.json`, phase JSON sidecars | UNVERIFIED — no config schema/signature check found in tree (`scripts/phases/phase02_config.py` loads and re-emits via `atomic_write` with no validation gate) | `atomic_write` prevents torn reads (`scripts/common.py:55`, `scripts/common.py:82`) | Medium: a writer who can edit config can change protection posture silently. | TOCTOU — trial state (concurrent runs race read-modify-write) | Sealed last-seen dotfile (`~/.local/state/nixon-trial/`) | Build-time path takes POSIX `LOCK_EX` (`obfuscator/trial_bind.py:97`, `obfuscator/trial_bind.py:329`); emitted runtime snippet takes **no** lock by design (`obfuscator/trial_bind.py:467`) | Monotonic HMAC-sealed writes: worst case one stale rollback window, absolute deadline still holds (`obfuscator/trial_bind.py:331`) | Low. Accepted by design; documented at `obfuscator/trial_bind.py:467`. |
| TOCTOU — build outputs (torn artifact reads) | `build/` artifacts, phase sidecars | `atomic_write` temp-then-`os.rename` (`scripts/common.py:55`, `scripts/common.py:82`) | Readers never see partial files | Low. |
| DLL / shared-lib hijack (Windows loader search order) | `stub_win` DLL resolution, pipeline reflective loader | Reflective import resolution + `GetModuleHandleA` verification (`native/stub_win.cpp:581`, `native/stub_win.cpp:602`); pipeline loader source (`obfuscator/core/pipeline.py:2701`) | Reflectively-loaded DLL has no OS module entry so `GetModuleHandle` cannot be tricked into blessing a planted DLL on disk; system DLLs resolved via guarded `LoadLibraryA`/`GetProcAddress` (`native/stub_win.cpp:285`, `native/stub_win.cpp:725`) | Medium: second resolution site (`native/stub_win.cpp:1955`) and search-order hardening beyond reflective load are not exhaustively audited. |
| Path traversal (`-o` / payload paths) | `-o/--output` staging path, payload path | Guard refuses `-o` outside build dir unless `--force-output` (`obfuscator/core/pipeline.py:386`, `obfuscator/core/pipeline.py:390`; CLI flag `scripts/build.py:366`) | `realpath` containment check; silent overwrite of arbitrary files refused | Low when default used; `--force-output` explicitly re-opens the footgun (operator opt-in). |
| Symlink attacks — trial state file | State-file write swaps link target | `O_NOFOLLOW` on state write (`obfuscator/trial_bind.py:382`) and in emitted snippet (`obfuscator/trial_bind.py:620`) | Symlinked state path fails instead of following | Low. |
| Symlink attacks — temp files | `secure_temp` build artifacts | `O_EXCL \| O_CREAT \| O_RDWR` + mode `0o600` + `fchmod` (`obfuscator/secure_temp.py:26`, `obfuscator/secure_temp.py:221`); snippet counterpart same flags | Exclusive create defeats pre-planted symlinks at that path | Low-medium: `O_NOFOLLOW` is NOT set on temp writes (verified absent) — an attacker who can pre-create the exact random name is still blocked by `O_EXCL`, but symlink hardening is partial. |
| Env manipulation (`NIXON_*` vars) | Every gate reads env at runtime | `obfuscator/vm_score.py:417` (`NIXON_KOD` default `"0"` = report-only), `obfuscator/kill_ladder.py:247` (`NIXON_LADDER_DEBUG` default `"0"` = silent), `obfuscator/driver_blocklist.py:292` (`NIXON_DRIVER_CHECK` default disarmed), `obfuscator/audit_hook.py:361` (`NIXON_AUDIT_TIMING` default `"0"` = off) | Fail-safe defaults: tamper *detection* gates default ON (snapshot, stdlib-audit, audit-hook plant); *kill-on-detect actions* and diagnostics default OFF, so a scrubbed env degrades to report-only, never to silent-pass-with-kill-disabled on integrity verdicts (verdicts still return `mismatch`/`tampered`) | Medium: `NIXON_SNAPSHOT_OFF` / `NIXON_STDLIB_AUDIT_OFF` / `NIXON_AUDITHOOK_PLANT_OFF` are explicit opt-outs — anyone controlling the runtime env can disable gates (documented operator escape hatches, not stealth). |
| Forged telemetry (fake attestations / gate reports) | Gate verdict strings, relay attestation channel | UNVERIFIED for loader gates — verdicts are in-process strings with no authentication envelope; relay attestation uses an incrementing nonce (`relay/src/attestation.rs:35`) | Trial/watermark/snapshot bindings are HMAC-keyed so forgery needs the build key; verdicts feed `_nx_kill` locally, not a remote trust decision | Medium: no consumer should treat a loader's self-report as proof of integrity. |
| Replay — trial last-seen rollback (`date -s`) | Trial state dotfile | Sealed last-seen stamp `seal_last_seen` / `unseal_last_seen` (`obfuscator/trial_bind.py:222`, `obfuscator/trial_bind.py:235`); `now < last_seen - tolerance` → `rollback` (`obfuscator/trial_bind.py:370`); tampered seal → fail-closed (`obfuscator/trial_bind.py:364`) | Rollback detected within 300 s tolerance (`ROLLBACK_TOLERANCE_S`); deleting the dotfile restarts `last_seen` at now (documented, `obfuscator/trial_bind.py:44`) | Low-medium: clock jumps inside tolerance + fresh dotfile extend the window; absolute deadline still bounds it. |
| Replay — nonce reuse (section crypto, proofs) | Split-bootstrap sections, ledger proofs | Per-section fresh `os.urandom(16)` nonce (`obfuscator/section_split.py:69`); distinct HMAC domain separators for trial vs last-seen (`obfuscator/trial_bind.py:60`) | Nonces never reused across builds/sections; seals are domain-separated | Low. |
| Corrupted state (truncated/edited dotfiles, torn JSON) | Trial dotfile, config sidecars | `unseal_last_seen` raises `ValueError` on tamper (`obfuscator/trial_bind.py:242`, `obfuscator/trial_bind.py:250`) → verdict `tampered`, never `ok` (`obfuscator/trial_bind.py:254`) | Fail-closed: corrupt state kills instead of passing | Low. Note: vacuous-empty contexts (`files={}` → `"ok"`) are possible only when the build baked nothing — pipeline always bakes a non-empty set. |
| Compromised update mechanism | Self-update / auto-download path | No auto-update mechanism found in tree — UNVERIFIED as absent-by-inspection (the `urllib.request.urlopen` calls in `obfuscator/core/pipeline.py:720,865,896,983` are cloud-deploy calls, not self-update) | Nothing to exploit if nothing phones home for code; verify before relying | Low-medium: absence-by-inspection is not a control; any future updater must require artifact-signature verification (`scripts/artifact_sign.py:31`) before execution. |

## Residual-risk summary

- **HIGH / accepted:** malicious local admin (no software control helps).
- **Require operator discipline:** opt-in gates left disarmed (driver-check,
  artifact signing), `--force-output`, `NIXON_*_OFF` escape hatches.
- **UNVERIFIED (future work):** config schema validation, hash-pinned
  dependencies, authenticated gate telemetry, updater signature policy.
