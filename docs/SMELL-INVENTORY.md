# Swallowed-exception inventory

Generated by walking the AST of every production module and recording
`except` handlers whose entire body is `pass`, `continue`, `return`, or a
bare constant. Vendored corpora (`scripts/transfer/corpus`), test fixtures,
`archive/`, and `ci-artifacts/` are excluded.

This is a reading aid, not a defect list. A swallowed exception is the
correct shape for a best-effort path (probing an optional tool, releasing a
lock, reading a file that may not exist). It is a defect only when the
swallow turns a *denial* into an *allowance*.

## Security-relevant subset

Every swallowed handler inside a function whose name matches
`verif|check|valid|gate|auth|licen|integrit|armed|block|deny|allow|trust|
sign|tamper|lock|unlock|expire|trial|hwid|guard|safe` was read and classified.
The verdict-returning ones are fail-closed:

| Site | On error |
|---|---|
| `trial_bind.verify_token` | `return False` |
| `trial_bind.check_trial` | `return "tampered"` |
| `watermark_gate.verify_tag` | `return False` |
| `frozen_snapshot._check_snapshot_impl` | `return "tampered"` |
| `core/utils._verify_download_zip` | `return False`, and the archive is deleted |
| `artifact_sign.verify_ed25519_bytes` | `return False` (4 sites) |
| `artifact_sign.verify_artifact` | `return False` |
| `proofs/proof_carrying.verify_certificate` | `return False` |
| `artifacts/bundler.verify_bundle` | `{"valid": False, ...}` |
| `verification_bundle/bundler.verify_bundle` | `(False, [...])` |
| `proof_soundness/oracle.check_semantic_equivalence` | `return False` |
| `stdlib_audit.verify_audit` | `GATE_MISMATCH` on a hash mismatch; unresolvable targets are skipped by design |

The remaining sites are best-effort: lock release, optional-tool probes,
`sys.platform`-specific attribute reads, and evidence collectors that must
never raise into a build.

## Known load-bearing swallows

These are the ones where a change would be felt:

- `obfuscator/core/pipeline.py` — the per-file transform loop. A transform
  that raises on one file must not abort the build; the failure is counted
  and reported.
- `obfuscator/kill_ladder.py`, `stdlib_audit.py`, `frozen_snapshot.py` —
  gate *emission*. These were fail-open until round 1; the emission paths
  now raise `SystemExit` and the swallows that remain are inside the
  runtime snippets, where a raise would kill the artifact.
- `obfuscator/secure_temp.py` — cleanup on the error path. Swallowing here
  is what keeps the original exception visible.
- `obfuscator/driver_blocklist.py` — 50 handlers, all in evidence
  collection. The module is documented as never raising.
