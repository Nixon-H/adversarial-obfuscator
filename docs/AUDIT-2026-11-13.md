# Audit 2026-11-13 — whole-repo smell / bug / issue sweep

Scope: all first-party production code — `obfuscator/`, `scripts/` (minus
`scripts/transfer/corpus/` vendored libs), `irgen/`, `llvmgen/`, `encrypt/`,
`vm/`, `runtime/`, `examples/`, root `*.py`, `*.rs/*.c/*.h` — 533 Python files
(~227k lines) + ~10k lines Rust/C. Excluded as vendor/fixture: `corpus/`,
`archive/`, `tests/fixtures/`, `tests/test_data/`, `docs/research/` generated
code. Tests were used as context only.

Method: ruff (F,B,SIM,RET,PLW,E9) + bandit (703 findings triaged) + targeted
grep pattern sweeps (bare except, eval/exec, shell=True, os.system, mktemp,
pickle/yaml, chmod) + full reads of the security-critical modules
(licensing, chacha20, string_crypto, key_emit, split_bootstrap, trial_bind,
watermark_gate, hwid, hwid_lock, secure_temp, audit_hook, section_split,
archive_safety, encrypt/aes, vm/interpreter dispatch) + execution checks
(RFC 8439 / NIST vectors, tamper tests, malformed-input tests).

## Verified clean (execution-checked, not just read)

- **ChaCha20** matches the RFC 8439 §2.3.2 block test vector; AEAD
  roundtrips and rejects tampering (HMAC-SHA256 tag, `compare_digest`,
  verify-before-decrypt); the KEK-stub variant compiles and decrypts.
  `obfuscator/chacha20.py`.
- **AES-256** (pure Python) matches the NIST single-block vector; CTR
  roundtrips. `encrypt/aes.py`.
- **Shamir split-bootstrap** roundtrips 20/20 random 32-byte keys with any
  2-of-3 shares (GF(251) hex-bridge is correct).
- **Section split** roundtrips; tampered section, wrong key, and missing
  section are all rejected (HMAC per section + count/index/key_hint/length
  checks). `obfuscator/section_split.py`.
- **Licence tokens**: Ed25519 sign/verify, fail-closed HWID binding,
  schema/expiry/future-issuance checks; build-side pin is
  `sha256(canonical(payload))` of a signature-verified token (sound: runtime
  forgery needs a sha256 preimage; bearer replay is inherent and documented).
- **secure_temp**: O_EXCL|O_CREAT|O_NOFOLLOW 0600 + fsync + fchmod, symlink-safe
  unlink, stale purge. **archive_safety**: resolved-path confinement +
  `filter="data"` on 3.12+ (B202 is a false positive there). **hwid**: sysfs
  MAC read, no `uuid.getnode()` subprocess fallback. **VM dispatch**: unknown
  opcode halts, `_read_byte` is PC-bounds-checked.
- No `shell=True`, no `os.system`, no `mktemp`, no unsafe pickle/yaml anywhere
  in production code; `exec()` appears only in the loader runtime (by design).
- `random` (173 bandit B311 hits) is used only for cosmetic obfuscation
  (names, chaff, masks); all key material comes from `secrets`/`os.urandom`.
- MD5 uses (B324) are name-mangling / project-hash / VM state-hash only —
  not key material.

## Findings

### MEDIUM

1. **Default-on integrity gates silently degrade to `DISABLED` on any emitter
   error** — `obfuscator/core/pipeline.py`: snapshot gate (~1445-1456),
   stdlib-audit gate (~1489-1504), kill-ladder emit (~1499-1504,
   `except Exception: pass`), trial gate (~1552-1555), watermark gate
   (~1598-1601), audit-hook plant (~3328-3335). Each wraps the emit in
   `try/except Exception` and appends `GATE = "DISABLED"` on failure. A bug
   in gate emission therefore ships an artifact *without* a protection the
   user asked for (or that is default-on) and with no error. Related: if the
   kill ladder fails to emit, gates that do fire call an undefined `_nx_kill`
   → NameError at runtime instead of the intended silent exit 137.
   Recommendation: hard-fail the build (or at minimum print a loud warning)
   when a requested/default-on gate cannot be emitted.

2. **Silent crypto downgrade in the payload seal** —
   `obfuscator/core/pipeline.py` `Nixon_Enc_AES_CTR` (~582-614): if neither
   `cryptography` nor pyCrypto imports, it falls back to `Nixon_Enc_blob`, a
   rolling `sha256` XOR stream (no AES). CRYPTO_REVIEW.md documents the
   fallback, but the loader-side availability probe comment warns the loader
   must not claim AES-CTR it does not have — a build/load mismatch here is
   silent. The pyCrypto branch (B413) is also a deprecated library. Keep the
   fallback, but record which seal was used in the artifact manifest so
   verification can assert it.

3. **`scripts/build.py --help` epilog references ~10 removed flags** — lines
   ~660-683 (`--phase2`, `--phase2-only`, `--classify`, `--adversarial-injection`,
   `--adversarial-level`, `--adversarial-loop`, `--deobfuscation-threshold`,
   `--phase2-extras`, `--microjit`, `--oram`, `--rop`, `--cross`,
   `--licence-token`, `--skip-irgen/--skip-llvmgen`), all verified
   `unrecognized arguments` today. Copy-pasting the examples fails. Several
   log strings still use the old `--skip-irgen`/`--skip-llvmgen` spelling
   (lines 317, 1824, 1966, 2295). Same class of staleness the 2026-11-12
   consolidation fixed in docs but missed in the epilog/log strings.

### LOW

4. **`licensing.verify()` raises uncaught `AttributeError` on a non-dict
   payload** — verified: `{"payload": 123, "sig": "00.."}` →
   `AttributeError: 'int' object has no attribute 'get'` instead of
   `LicenceError`/`REJECTED` (`obfuscator/licensing.py`, the `payload.get("schema")`
   line). Fails closed in effect, but crashes the CLI with a traceback.
   Fix: validate `isinstance(payload, dict)` before use.

5. **`chain_owner_of` crashes with `TypeError` on a null RPC result** —
   `int(result, 16)` when `result` is `None` (`obfuscator/licensing.py`).
   Should raise a clean `RuntimeError`.

6. **`save_token` writes the credential with default umask** (typically 0644,
   world-readable), predictable `.tmp` sibling, no fsync
   (`obfuscator/licensing.py:372-379`). Use 0600.

7. **Tar extraction fallback branch is weaker than the guarded path** —
   `archive_safety.extract_tar_confined`: when `tarfile.data_filter` does not
   exist (Python without the 3.9-3.11 backports), it name-checks members but
   calls `extractall` unfiltered, so a symlink member pointing outside could
   escape. Current interpreters (3.12+) are safe; the fallback is
   env-dependent.

8. **`trial_bind.check_and_update` fallback write can follow a symlink** —
   when `O_NOFOLLOW` is unsupported (`AttributeError`), the fallback
   `open(path, "w")` runs unguarded (only ELOOP/EMLINK are refused).

9. **Stealth level inconsistency** — `scripts/build.py:_apply_rea_shields`:
   at `--anti-rea-level stealth`, `provenance_poison` stays `True` while
   `poison_level` is 0; consumers keying off the boolean may apply a
   default-strength pass. Align the boolean with the level.

10. **Assert-based locks are stripped under `python -O`** —
    `obfuscator/audit_hook.py:99-100` (serialized-threshold lock). Build-time
    only, informational.

### INFORMATIONAL / smell inventory

- 192 `try/except: pass` (bandit B110), concentrated in
  `pipeline.py` (41), `transforms.py` (22), `utils.py` (15) — mostly
  intentional feature probes, but several guard security-gate emission
  (finding 1).
- Ruff: 74 `subprocess.run` without explicit `check=` (all check
  `returncode` manually — fine), 12 B023 loop-closure captures
  (`irgen/microjit.py:553`, `pipeline.py:3337`, `scripts/proofs/…`,
  `scripts/transfer/reproduce.py`), 16 PLW0603 globals (cache flags),
  40 SIM115 `open()` without context manager, 84 SIM105.
- `hwid_lock` uses MAC-then-encrypt (tag over plaintext, then stream
  encryption) rather than encrypt-then-MAC; safe here because the tag is
  compared after decryption and wrong keys fail the compare, but EtM (as in
  `chacha20.aead_*`) is the better pattern.
- Dead code: `try: pass finally: pass` at the end of the secure-temp loader
  snippet (`secure_temp.py:emit_loader_snippet`).
