# Payload Contract — `payload.h`

`native/payload.h` is generated by `scripts/generate_payload_h.py`. It is a
self-contained C++17 header: a consumer may include it first, without relying on
a stub or another header to provide types, allocator declarations, or platform
headers. The historical Windows/Linux stubs were archived, but the symbols below
remain the payload contract for native consumers.

## Required Includes

Every generated header includes these dependencies directly:

```cpp
#include <cstddef>   // std::size_t / size_t
#include <cstdint>   // uint8_t
#include <cstdlib>   // std::malloc / std::free on non-Windows platforms
#include <new>       // std::bad_alloc
#include <vector>    // std::vector and SecureVector
#ifdef _WIN32
#include <windows.h> // VirtualAlloc / VirtualFree and memory constants
#endif
```

The header uses `#pragma once`. Consumers must not need to include any of the
above before `payload.h`.

## Symbol Table

|---|--------|----------|---------|-------------|

## `SecureAllocator` and `_WIN32` Behavior

- `allocate(n)` first rejects `n > SIZE_MAX / sizeof(T)`, preventing multiplication
  overflow. Failure throws `std::bad_alloc`.
- On `_WIN32`, allocation uses
  `VirtualAlloc(nullptr, n * sizeof(T), MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE)`.
  Deallocation uses `VirtualFree(p, 0, MEM_RELEASE)`. This is whole-region
  allocation; it does **not** call `VirtualLock` and does not claim page locking.
- On non-Windows platforms, allocation uses `std::malloc(n * sizeof(T))` and
  deallocation uses `std::free(p)`.
- Before either release path, `deallocate(p, n)` overwrites all `n` elements with
  `T{}` through a volatile pointer. This zeroization applies to the allocated
  element count, not spare vector capacity.
- `SecureAllocator` instances compare equal across element types, as required for
  vector allocator interoperability.
- `_WIN32` guards only the allocator implementation and its `windows.h` include.
  Payload symbols and `SecureVector` are required on every platform.

## Endianness

- `NIXON_PYTHON_DLL` and `NIXON_RUST_BINARY` are opaque zlib byte streams; there is
  no endianness conversion.
- `NIXON_WORD_ARRAY` and `NIXON_DICT` are arrays of C strings; there is no
  endianness conversion.
- `NIXON_KEY_SALT` is an opaque `uint8_t` sequence; there is no endianness
  conversion.

## Structural Skeleton

The generated file uses definitions rather than `extern` declarations. The
placeholders below show the required order and shape; replace each `???` before
compiling.

```cpp
// payload.h
#pragma once

#include <cstddef>
#include <cstdint>
#include <cstdlib>
#include <new>
#include <vector>
#ifdef _WIN32
#include <windows.h>
#endif

template <typename T>
struct SecureAllocator {
    using value_type = T;

    SecureAllocator() = default;
    template <typename U>
    SecureAllocator(const SecureAllocator<U>&) noexcept {}

    T* allocate(std::size_t n) {
        if (n > static_cast<std::size_t>(-1) / sizeof(T))
            throw std::bad_alloc();
#ifdef _WIN32
        if (auto p = static_cast<T*>(VirtualAlloc(
                nullptr, n * sizeof(T), MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE)))
            return p;
#else
        if (auto p = static_cast<T*>(std::malloc(n * sizeof(T))))
            return p;
#endif
        throw std::bad_alloc();
    }

    void deallocate(T* p, std::size_t n) noexcept {
        volatile T* vp = p;
        for (std::size_t i = 0; i < n; ++i)
            vp[i] = T{};
#ifdef _WIN32
        VirtualFree(p, 0, MEM_RELEASE);
#else
        std::free(p);
#endif
    }
};

template <typename T, typename U>
bool operator==(const SecureAllocator<T>&, const SecureAllocator<U>&) { return true; }
template <typename T, typename U>
bool operator!=(const SecureAllocator<T>&, const SecureAllocator<U>&) { return false; }

template <typename T>
using SecureVector = std::vector<T, SecureAllocator<T>>;

constexpr uint8_t NIXON_OBF_KEY = 0x??;
const uint8_t NIXON_KEY_SALT[16] = { /* 16 bytes */ };

constexpr size_t NIXON_PAYLOAD_LEN = ???;
const char* NIXON_WORD_ARRAY[NIXON_PAYLOAD_LEN] = { /* payload words */ };
const char* NIXON_DICT[256] = { /* 256 unique words */ };

constexpr size_t NIXON_DLL_COMPRESSED_LEN = ???;
constexpr size_t NIXON_DLL_ORIGINAL_LEN = ???;
const uint8_t NIXON_PYTHON_DLL[NIXON_DLL_COMPRESSED_LEN ? NIXON_DLL_COMPRESSED_LEN : 1] = { /* bytes */ };

constexpr size_t NIXON_RUST_COMPRESSED_LEN = ???;
constexpr size_t NIXON_RUST_ORIGINAL_LEN = ???;
const uint8_t NIXON_RUST_BINARY[NIXON_RUST_COMPRESSED_LEN ? NIXON_RUST_COMPRESSED_LEN : 1] = { /* bytes */ };
```
